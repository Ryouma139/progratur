# Python リファレンス

このセクションでは、Python の文法・CPython の仕組み・標準ライブラリの使い方を、実際に動かせるコード例とともにまとめています。

## 構成

- **Python 文法** — `if` / `for` / `while` / `match` などの制御構文から、クラス・dataclass、例外処理、内包表記、デコレータ・ジェネレータ、async/await、型ヒントまで
- **ランタイム** — GIL (Global Interpreter Lock) とメモリ管理の仕組み
- **標準ライブラリ** — 基本型、コレクション、itertools/functools、ファイル I/O、JSON、HTTP 通信、スレッド/asyncio、日付・時間、暗号

左のサイドバーから読みたいトピックを選んでください。

:::tip[対象読者]
他言語の経験がある人が Python の書き方・考え方を素早くキャッチアップできることを目指しています。Python を初めて学ぶ人は、まず「Python 文法」の章から順に読むのがおすすめです。
:::
