Progratur は C# / Java / Python の文法・ランタイム・標準ライブラリを、実際に動くコード例とともにまとめるリファレンスサイトです。このブログでは、リファレンス本編には書きにくい**言語をまたいだ視点の読み物**を扱っていきます。

{/* truncate */}

## 扱う予定のテーマ

- 同じ課題を C# / Java / Python がそれぞれどう解決しているかの比較（HTTPクライアント、JSON処理、非同期処理など）
- 標準ライブラリのAPI設計における考え方の違い
- 各言語のランタイム（CLR / JVM / CPython）の特性が、書き方にどう影響しているか

リファレンス本編（[C#](/csharp/intro) / [Java](/java/intro) / [Python](/python/intro)）が「今どう書くか」を扱うのに対し、ブログでは「なぜそう設計されているか」「他の言語と比べてどう違うか」を掘り下げていきます。
