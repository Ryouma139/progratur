# C# & .NET リファレンス

このセクションでは、C# の文法・.NET ランタイムの仕組み・標準ライブラリの使い方を、実際に動かせるコード例とともにまとめています。

## 構成

- **C# 文法** — `if` / `for` / `switch` などの制御構文から、クラス、非同期処理、LINQ 構文、デリゲート・ラムダ式まで
- **.NET ランタイム** — CLR（共通言語ランタイム）とガベージコレクションの仕組み
- **標準ライブラリ** — 基本型、コレクション、LINQ 拡張メソッド、ファイル I/O、JSON、HTTP 通信、スレッド、日付・時間、暗号

左のサイドバーから読みたいトピックを選んでください。

:::tip[対象読者]
他言語の経験がある人が C# の書き方・考え方を素早くキャッチアップできることを目指しています。C# を初めて学ぶ人は、まず「C# 文法」の章から順に読むのがおすすめです。
:::
