# Java リファレンス

このセクションでは、Java の文法・JVM の仕組み・標準ライブラリの使い方を、実際に動かせるコード例とともにまとめています。

## 構成

- **Java 文法** — `if` / `for` / `switch` などの制御構文から、クラス・インターフェース、record・sealed class、ラムダ式、例外処理まで
- **JVM ランタイム** — JVM (Java Virtual Machine) の仕組みとガベージコレクション
- **標準ライブラリ** — 基本型、コレクション、Stream API、ファイル I/O、JSON、HTTP 通信、スレッド、日付・時間、暗号

左のサイドバーから読みたいトピックを選んでください。

:::tip[対象読者]
他言語の経験がある人が Java の書き方・考え方を素早くキャッチアップできることを目指しています。Java を初めて学ぶ人は、まず「Java 文法」の章から順に読むのがおすすめです。
:::
